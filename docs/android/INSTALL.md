# Android 安装与使用

## 最快安装

1. 打开 [Android 0.2.1 Beta 发布页](https://github.com/kkkkkk12138/xiaoshuo-huanming/releases/tag/v0.2.1-android-beta)。
2. 点击 `xiaoshuo-yijian-huanming-android-0.2.1-debug.apk`。
3. 下载完成后打开 APK。
4. 系统提示时，允许当前浏览器或文件管理器“安装未知应用”。
5. 安装完成后关闭该来源的“安装未知应用”权限。

只想安装使用时，不要下载 `Source code (zip)`、`Source code (tar.gz)` 或名称以 `DO-NOT-USE-old-signature-` 开头的旧文件，也不需要安装 Git、Android Studio 或其他开发工具。

## 使用网页换名

1. 在夸克、微信或其他 App 中打开无需登录的小说网页。
2. 点击“分享”。
3. 选择“小说一键换名”；如果没有显示，点击“更多”。
4. 在阅读页打开规则面板。
5. 输入原名和新名，点击“全部生效”。

应用不读取其他浏览器的登录状态。需要登录的网站不会要求你在本应用内输入账号密码。

## 使用 TXT 或 EPUB

1. 从桌面打开“小说一键换名”。
2. 点击“打开 TXT / EPUB”。
3. 在系统文件选择器中选择文件。
4. 添加换名规则并生效。

支持常见编码 TXT 和无 DRM 的可重排 EPUB2/EPUB3。

## 校验

将 APK 与同目录的 `.sha256` 文件放在一起，在 macOS/Linux 执行：

```bash
shasum -a 256 -c xiaoshuo-yijian-huanming-android-0.2.1-debug.apk.sha256
```

只有显示 `OK` 时才继续安装。校验失败表示文件不完整或已被修改。

## 覆盖升级

已安装 `0.1.1 (2)` 或 `0.2.0 (3)` 时，保留原应用，校验新版 APK 后直接覆盖安装 `0.2.1 (4)`。各版本的 application ID 与签名证书一致，升级会保留换名规则、最近阅读和阅读位置；若系统提示签名不一致，说明下载了错误资产，请不要卸载旧版绕过检查。

当前版本使用 Debug 证书。未来正式版切换到 Release 证书时可能无法直接覆盖安装，因此不要在测试版中保存无法重新创建的重要数据。

## 常见问题

### 分享面板找不到应用

先从桌面打开一次“小说一键换名”，再回到小说网页重新分享；在分享面板中点击“更多”查找。

### 网页要求登录

本应用不提供网站登录，也不读取夸克或其他浏览器的 Cookie。请从正规渠道下载 TXT/EPUB 后本地打开。

### Android 阻止安装

在系统提示中，仅允许当前用于下载 APK 的浏览器或文件管理器安装未知应用。安装后立即关闭授权。企业设备或家长控制设备可能由管理员禁止侧载，此时无法绕过系统策略。

### EPUB 无法打开

受 DRM 保护、固定版式、损坏或包含危险资源的 EPUB 会被拒绝。应用不会尝试破解 DRM。
